# XPlanner Agent Skills Guide

- Keep the public skill aligned with the verified remote XPlanner MCP contract.
- Do not document a tool, platform, filter, or atomic operation that the remote MCP server does not expose.
- Preserve draft-first behavior and explicit publish/delete intent.
- Keep one source idea → one post record → multiple platform texts as the default related-content model.
- Never add credentials, API keys, access tokens, or local configuration files to this repository.
- Run `npm test` after changing the skill, references, metadata, or installation documentation.
